# Source photographs

Original uploads. Next does not serve files from `app/`, so the originals live
here and `npm run photos` (scripts/make-photos.mjs) writes optimised banner and
inline versions into `public/photos/`, which is what the site loads.

| File | Used as |
| --- | --- |
| `tutor-and-student.jpg` | Homepage banner, partners hub, about page |
| `one-to-one-instruction.jpg` | Find hub, reviews hub, homepage one-to-one section |
| `online-tutoring.jpg` | Costs hub, blog hub, homepage online section |
| `UNUSED-huntington-branded-classroom.jpg` | **Not used.** The photo contains a sign reading "Property of Huntington Learning Corporation", so publishing it on this site would imply an affiliation with that company. |

Confirm you hold a licence for each photograph before the site goes live.
Replace a file and re-run `npm run photos` to swap the artwork everywhere.
